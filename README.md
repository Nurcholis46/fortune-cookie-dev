A make.fun entry: a program that writes one original line of fortune-cookie wisdom for a software developer.

The line (78 characters, one sentence):

> The estimate you give today is a fortune your future self must make come true.

Why this line: an estimate is a fortune you tell yourself — and then you are the one who has to make it come true. The fortune-teller and the fortune's victim are the same developer. It is true about a developer's day (estimates are the one prediction every developer is held to), reads like a real fortune cookie in a single breath, and turns that truth in a way no familiar saying does.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

It writes `entry.txt` into the output directory, checks the gate itself (1–120 characters, not only whitespace, one single line), chmods the file to 0644, and verifies the write by reading it back.
